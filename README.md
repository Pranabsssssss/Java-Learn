# java learning journey

practicing core java basics and building hands on exercises from scratch

## topics covered

- **module 1 to 4**: syntax setup print vs println variables data types and variable scopes
- **module 5 to 7**: operators math calculations boolean logic scanner user input
- **module 8 to 12**: if else conditionals ternary switch cases for loops while loops and nested patterns
- **module 13 to 15**: methods functions return values and method overloading
- **module 16 to 18**: string manipulation character scanning and math library functions
- **module 19 to 21**: arrays traversal min max searching and 2d matrices
- **module 22 to 23**: dynamic structures arraylists collections operations and stats
- **module 24 (mini project)**: console based grocery store inventory and cart manager
- **module 25**: capstone portfolio project

## how to run

compile any file using javac and run it with java

```bash
javac "module 1/exs1.java"
java -cp "module 1" exs1
```

for the mini project:

```bash
javac "module 24 (Mini Project)/exs1.java"
java -cp "module 24 (Mini Project)" exs1
```
